# Trang giới thiệu SafeWatch

Trang tĩnh (HTML + CSS + một ít JS), không phụ thuộc app Streamlit. Mở `index.html` là xem được.

- Nút **Dùng thử** trỏ tới app SafeWatch. Đổi địa chỉ app ở **một chỗ**: biến `APP_URL` cuối file `index.html`.
- Ảnh trong `img/` là ảnh chụp từ app thật. Hình động đầu trang là **minh hoạ** dựng bằng HTML (có ghi chữ "Minh hoạ").
- Font Be Vietnam Pro nằm trong `fonts/` (giấy phép OFL).

Đăng miễn phí: GitHub Pages (workflow `.github/workflows/landing.yml`), Netlify hoặc Vercel (thư mục gốc `landing/`).
